# First phone test

This file is for the team, not for a student conversation. Prove three beats on email alerts, one connected board, and one apply route before treating other boards or a live referral send as done.

1. Text the branch link. Reply yes when Cubbie asks to fetch it.
2. Walk setup in three stages: background, optional connections, then ready. The first role does not wait on Canvas, Drive, Notion, or Overleaf. Notifications stay off until they name a cadence. The profile, connections, and ready cards are one each, not one bubble per question.
3. Feed a role whose requirement conflicts with a saved fact. Expect one message, the quote, and no kit.
4. Say yes to a role that fits. Expect one question bundle, one "starting to build" text, then one package link. A real project is still in the resume. No invented role was added.
5. Agree to the package. The form is filled and not submitted. One question asks whether to submit.
6. Say yes. The employer's confirmation words are in the local index and on that Notion row. If the page does not confirm, the status stays unsubmitted in both places.
7. Run the check again with the same job id. It is not asked again. A second role at the same company, with a different job id, still gets a verdict.
8. The Hub page shows the cadence, the Overleaf link, and the current resume link.
